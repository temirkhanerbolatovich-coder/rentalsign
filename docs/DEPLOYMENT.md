# Бесплатное размещение RentalSign

Выбраны только бесплатные ресурсы: Render Free для Next.js и Neon Free для PostgreSQL. HTTPS и уникальный поддомен `*.onrender.com` предоставляет Render. Платные диски, тарифы и Render PostgreSQL не создаются.

В бесплатном Render локальные файлы исчезают при рестарте/простоях, поэтому SQLite применяется только локально. Договоры, ссылки, сессии и журнал облачного приложения хранятся во внешнем PostgreSQL. PostgreSQL-модели генерируются из канонического `prisma/schema.prisma`; локальный SQLite-файл не изменяется и не публикуется.

## Облачная конфигурация

`render.yaml`: один Node.js web-сервис, plan=free, без disks/databases, регион Frankfurt. Автодеплой отключён: публикации запускаются после проверки исходников. Команды:

```text
npm ci --include=dev && npm run build:cloud && npm prune --omit=dev
npm run start:production
```

Серверный адрес берётся из `RENDER_EXTERNAL_URL`, установленного Render. Для собственного домена можно явно задать HTTPS-origin в APP_URL. Не оставляйте APP_URL=http://localhost:3000 на сервере: это неверные ссылки и отказ CSRF-проверки.

Секреты задаются в настройках провайдера, а не в исходниках:

| Переменная           | Значение                                                                      |
| -------------------- | ----------------------------------------------------------------------------- |
| DATABASE_PROVIDER    | postgresql                                                                    |
| DATABASE_URL         | Neon PostgreSQL connection URL, TLS sslmode=require; рекомендуется pooled URL |
| DIRECT_DATABASE_URL  | Прямой Neon URL для миграций, TLS sslmode=require                             |
| TOKEN_ENCRYPTION_KEY | 32 случайных байта в hex; сохранять при любых рестартах                       |
| ADMIN_EMAIL          | Email единственного первоначального администратора                            |
| ADMIN_PASSWORD       | Случайный пароль 12–128 символов; только для первого запуска                  |

`start:production` проверяет origin, ключ, диапазоны сроков и TLS, применяет PostgreSQL-миграции и создаёт администратора только при пустой таблице Admin. Повторный старт не сбрасывает пароль, не создаёт публичных тестовых аккаунтов и не запускает seed. `/api/health` возвращает 200 только при доступной мигрированной базе, иначе 503; ответ не раскрывает параметры подключения.

Для SQLite на отдельном сервере также поддерживается production-init с абсолютным DATABASE_URL, но этот вариант требует постоянного диска и **не используется** в бесплатной облачной конфигурации.

## Сохранение локальных данных

Новая облачная база по умолчанию пустая. Локальная demo-база и её учётная запись сохраняются на компьютере. Уже выданные localhost-ссылки сами по себе не становятся внешними: нужен перенос соответствующих записей базы и encryption key либо создание новых договоров/ссылок в облачной системе. Не пересылайте локальный `.env` или SQLite через публичный репозиторий.

## Проверка после размещения

1. Подтвердить live-развёртывание и точную ревизию источников.
2. Проверить HTTPS `/api/health`, `/login`, отказ анонимному административному API.
3. Войти с серверным аккаунтом, создать вымышленный объект и договор.
4. Выпустить ссылку и убедиться, что она начинается с фактического серверного HTTPS-origin.
5. Открыть ссылку без сессии администратора, скачать PDF, выполнить демодействие.
6. Проверить итоговый PDF и DEMO_SIGNED в карточке администратора; повторный sign должен вернуть 409.
7. Перезапустить приложение и проверить сохранность записи и работоспособность той же ссылки.

До прохождения этих шагов внешние ссылки не считаются проверенными. Демопредупреждение остаётся обязательным; внешнее размещение не делает действие ЭЦП.

## Ограничения бесплатных тарифов

Render Free засыпает после 15 минут простоя, первый запрос запускает сервис заново и может ждать около минуты. Квота Free compute разделяется с другими бесплатными сервисами аккаунта. Не создаются таймеры для обхода простоя или платные улучшения.

Neon Free имеет ограниченные storage/compute/transfer квоты. При достижении лимита работу нужно ограничить или пересмотреть размещение с владельцем; автоматически переключаться на платный план запрещено. Бесплатный поддомен не является приобретённым доменом второго уровня. Доступность сторонних бесплатных сервисов не гарантируется.

Источники: [Render Free](https://render.com/docs/free), [переменные Render](https://render.com/docs/environment-variables), [Neon Free](https://neon.com/docs/introduction/plans).
