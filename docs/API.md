# API

JSON, UTF-8. Административные методы требуют живой HttpOnly-сессии и владения объектом. Все изменяющие методы, включая login и публичное демоподписание, требуют `Origin`, точно совпадающий с `APP_URL`. JSON-тела требуют `Content-Type: application/json`. Максимальный размер JSON-тела — 96 KiB; загрузка фотографии имеет отдельное ограничение 8 МиБ.

## Маршруты

`GET /api/health` — публичная проверка мигрированной базы без персональных данных; 200 `{status:"ok"}` или 503 `{status:"unavailable"}`.

| Метод  | URL                            | Действие                                                    |
| ------ | ------------------------------ | ----------------------------------------------------------- |
| POST   | `/api/auth/login`              | `{email,password}`; создать сессию                          |
| POST   | `/api/auth/logout`             | Удалить сессию, сбросить cookie                             |
| GET    | `/api/properties`              | Список своих объектов, включая архив                        |
| POST   | `/api/properties`              | Создать объект                                              |
| POST   | `/api/catalog/:slug/property` | Добавить публичную квартиру в свои объекты или вернуть существующий ID; сессия + Origin, без тела |
| POST   | `/api/catalog/import`        | Добавить недостающие квартиры в свои объекты; `{imported,total}`, без очистки демоданных |
| GET    | `/api/contract-template`     | Свои частные реквизиты и условия новых договоров |
| PUT    | `/api/contract-template`     | Сохранить полный шаблон по строгой схеме; сессия + Origin + JSON |
| PATCH  | `/api/properties/:id`          | Полная форма объекта **либо** `{archived:boolean}`          |
| PUT | `/api/properties/:id/listing` | Полностью сохранить публичную карточку назначенного владельца, с проверкой revision |
| GET | `/api/properties/:id/photos` | Своя галерея: `{revision,photos}`; исходные фото до первого изменения |
| POST | `/api/properties/:id/photos` | Сессия + Origin; бинарный JPEG/PNG/WebP, заголовок `X-Gallery-Revision`; вернуть обновлённую галерею |
| PATCH | `/api/properties/:id/photos` | Сессия + Origin + JSON `{revision,action,key}`, действия `delete`, `cover`, `left`, `right` |
| GET | `/api/property-photos/:id` | Обработанный WebP; публично только для назначенного владельца каталога, иначе только владельцу |
| GET    | `/api/contracts`               | Свои договоры, effectiveStatus и события                    |
| POST   | `/api/contracts`               | Сохранить черновик                                          |
| GET    | `/api/contracts/:id`           | Детали своего договора                                      |
| PATCH  | `/api/contracts/:id`           | `{content:ContractInput,revision}`; только черновик         |
| POST   | `/api/contracts/:id/link`      | `{ttlHours,revision}`; зафиксировать версию и выдать ссылку |
| GET    | `/api/contracts/:id/link`      | Получить действующую ссылку для копирования                 |
| DELETE | `/api/contracts/:id/link`      | Отозвать ссылки; недоступно после DEMO_SIGNED               |
| POST   | `/api/contracts/:id/duplicate` | Новый черновик с новым ID и номером                         |
| POST | `/api/contracts/:id/booking-cancellation` | Отменить бронь демоподписанного договора: сессия, Origin, JSON `{reason}` от 1 до 500 символов; снимок договора сохраняется |
| GET    | `/api/contracts/:id/pdf`       | Последний снимок / черновик; PDF администратора             |
| GET    | `/api/sign/:token`             | Публичный снимок при действующей ссылке                     |
| POST   | `/api/sign/:token`             | `{acknowledged:true}`; демонстрационное действие            |
| GET    | `/api/sign/:token/pdf`         | Предварительный / итоговый демо PDF                         |

PropertyInput: `name,address,type,unit,description,rent,deposit`. type: `APARTMENT`, `APARTMENTS`, `HOTEL`. Суммы: целые значения 0–100 000 000 тенге.

ContractInput: `propertyId,landlordName,landlordId,landlordPhone,tenantName,tenantId,tenantPhone,checkIn,checkOut,rent,deposit,additionalTerms,obligations,payment,depositTerms,damage,handover`. ID сторон — пустая строка либо 12 цифр; это проверка формата, а не идентичности. Даты ISO 8601 с offset; checkOut > checkIn. Текст условий — до 10 000 символов на поле, суммарный лимит JSON сохраняется. Неизвестные ключи отклоняются.

Дополнительные необязательные поля ContractInput: `landlordDocument` (до 200 символов), `landlordDocumentIssued` (до 300), `tenantDocument` (до 300), `tenantAddress` (до 500). Старые снимки без них поддерживаются. Шаблон содержит только поля `landlord*`, пять блоков условий и `additionalTerms`; квартиры, арендатора, даты и суммы он не принимает. Лимиты совпадают с формой; пустые реквизиты в шаблоне допустимы, в готовом договоре обязательные имя/телефон по-прежнему проверяются.

Для `Property` с `catalogSlug` договор требует `rent > 0`: это согласованная общая сумма за весь период. Форма нового договора предлагает текущий суточный тариф каталога × количество 24-часовых суток, округлённых вверх, и позволяет скидку или ручное изменение. API сохраняет присланную итоговую сумму и не пересчитывает существующие договоры. Импорт возвращает `{id}`; неизвестный slug — 404, собственный архивный объект — 409. Повторный импорт не обновляет существующий объект. `catalogSlug` устанавливается сервером и не принимается обычным PropertyInput. Публичный перечень дополняется карточками назначенного владельца; доступ к `/api/properties` остаётся закрытым.

`PUT /api/properties/:id/listing` принимает `{revision,title,address,description,arrivalInstructions,mapUrl,priceMin,priceMax}`. Первое сохранение использует `revision:0`, успешный ответ — `{revision:1}`, последующие сохранения требуют текущую версию и увеличивают её; конфликт — 409. Название обязательно, до 160 символов; адрес обязателен, до 300; описание и инструкции — `null` или до 3000; ссылка — `null` или HTTPS-домен 2ГИС (`2gis.kz`, `2gis.ru`, `2gis.com` и их поддомены), до 1000 символов. Цены — `null` или целые 1–100 000 000; верхняя цена не меньше нижней и не задаётся без неё. Доступны только активные связанные объекты назначенного владельца каталога; чужой объект — 404. Адрес одновременно сохраняется в объекте для будущих договоров. Уже сохранённые договоры и версии не меняются; при последующем редактировании черновика его сведения могут быть сформированы заново из текущего объекта.

## Ответы

Ошибки: `{ "error": "понятное сообщение" }`. Коды: 400 — валидация; 401 — нет сессии; 403 — Origin; 404 — объект/токен не найден; 409 — подписано, зафиксировано или конфликт revision; 410 — истекла/отозвана ссылка; 413 — тело слишком велико; 415 — неверный Content-Type; 429 — лимит; 500 — безопасное общее сообщение без внутренних данных.

Повторное демоподписание возвращает 409. Клиент может повторно читать действующую ссылку и после демоподписания. PDF: `application/pdf`, attachment, private/no-store. Запрос без сессии к административному PDF возвращает 401.

WhatsApp — обычный URL `https://wa.me/<digits>?text=<URL-encoded message>`. Ключ API не требуется; приложение не отправляет сообщения автоматически.


## Ручная занятость

Контракт `GET/POST/DELETE /api/availability`, включая автоматически вычисленные брони по действующим и подписанным договорам, авторизация и публичные поля описаны в [QUTTY_QONAQ.md](QUTTY_QONAQ.md#api-контракт).

Галерея ограничена 50 фотографиями. Загрузка проверяет формат и фактическое содержимое, ограничивает размер, удаляет метаданные и сохраняет WebP. Устаревший `revision` возвращает 409 и требует перечитать галерею. Удаление загруженного файла удаляет его из БД; старые исходные статические файлы и ранее кэшированные копии могут оставаться доступными по прямой ссылке. Публикуются только галереи связанных с каталогом объектов владельца `CATALOG_OWNER_EMAIL` (резервное значение — `ADMIN_EMAIL`). Галереи других владельцев остаются приватными.

При создании или изменении договора и при выдаче ссылки проверяются ручные отметки владельца (целые дни) и фактическое время активных броней того же объекта. Между выездом и следующим заездом должно быть не менее двух часов; конфликт возвращает HTTP 409. Черновики не занимают даты. Отмена брони после демоподписания сохраняет договор и историю, снимает автоматическую бронь, а публичный договор по действующей ссылке возвращает `bookingCancelled: true` без причины отмены. Повторная отмена — 409, чужой договор — 404. Отмена брони не является юридическим расторжением.

`POST /api/availability` при пересечении с активной бронью владельца возвращает 409 с кодом `BOOKING_OVERLAP` и ничего не сохраняет. После предупреждения владелец может повторить запрос с `confirmOverlap: true`. Проверка предупреждает о состоянии на момент чтения; она не запрещает пересечения и не является гарантией отсутствия гонки с одновременной выдачей ссылки.
