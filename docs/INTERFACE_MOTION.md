# Типографика и движение интерфейса

Обновление 2026-10-30 по видеореференсу со светом, следующим за выбранным пунктом.

- `LightNavigation` используется в публичном каталоге, боковом меню и мобильной навигации кабинета. Янтарный индикатор перемещается при наведении и фокусе клавиатуры, после ухода возвращается к текущему маршруту. На телефоне работает обычное нажатие ссылки. `aria-current` отражает маршрут, а не наведение. Переходы между кабинетом и каталогом перезагружают соответствующий layout, поэтому движение между ними не непрерывное.
- Геометрия индикатора пересчитывается через `ResizeObserver` при изменении ширины и загрузке шрифта. Без JavaScript ссылки и выделение текущего маршрута текстом доступны.
- Заголовки мягко появляются, фотографии проявляются при переключении; выбранная миниатюра имеет янтарную рамку и свечение. Нет автоматического переключения фотографий.
- `prefers-reduced-motion: reduce` отключает эти анимации и переходы. Видимый фокус клавиатуры остаётся.
- Интерфейс использует локальный вариативный Noto Sans (100–900), `next/font/local`, `display: swap`. Источник: Google Fonts, `ofl/notosans/NotoSans[wdth,wght].ttf`, лицензия SIL OFL в `src/app/fonts/OFL.txt`. Сохранены латиница, кириллица, казахские буквы, типографские знаки и ₸; ширина зафиксирована на 100, файл сжат в WOFF2 (~120 КБ). Запросов к Google Fonts при посещении нет.
- Шрифт и анимации относятся к веб-интерфейсу. Генерация PDF и сохранённые снимки договоров не менялись.

Проверки: `npm run lint`, `npm run typecheck`, `npm run build`, `npx playwright test e2e/ui-ux.spec.ts e2e/catalog.spec.ts`. Сценарии проверяют клавиатуру, положение индикатора, уменьшение движения, галереи и отсутствие горизонтального переполнения на ширинах 320–1440 px. Реальные устройства проверяются отдельно.
