# ADR-005: Oracle Cloud для приложения с сохранением Neon и старых ссылок

Статус: принято 2026-11-01.

## Контекст

Владелец попросил работающий постоянно бесплатный хостинг. Render Free останавливается при простое; существующие договоры и персональные ссылки уже используют Render и базу Neon. Пользователь разрешил удалить ненужный сервер SAQ и его диск, чтобы освободить ресурсы Oracle.

## Рассмотренные варианты

- Оставить Render Free: минимальные изменения, но сервис засыпает при простое.
- Oracle Always Free с существующей базой Neon: приложение работает на отдельной машине, сохраняются данные и ранее выпущенные ссылки, но возрастает эксплуатационная нагрузка.
- Перенести базу на виртуальную машину: меньше внешних зависимостей, но потребуются отдельные процедуры восстановления, обновления базы и резервирования.

## Решение и причины

Основное приложение размещено на Oracle Always Free `VM.Standard.E2.1.Micro`, HTTPS обеспечивает Caddy. База остаётся в Neon, а Render сохранён и обновлён до той же версии приложения для поддержки старых ссылок. Попытка использовать более мощную бесплатную ARM-машину в регионе завершилась отсутствием свободной ёмкости. Решение сокращает простой из-за остановки приложения Render и не требует переноса клиентских записей.

## Последствия и риски

Две копии приложения обращаются к одной базе, поэтому изменения правил работы и миграции нужно согласовывать. Бесплатные сервисы не гарантируют постоянную доступность; Neon может приостанавливаться, Oracle может отозвать простаивающую машину. Адрес `sslip.io` зависит от публичного IP; его изменение нарушит ранее выданные ссылки без перенаправления. Сервер и HTTPS-сертификаты требуют обслуживания. Полная процедура восстановления и регулярные независимые резервные копии пока не настроены.

## Дальнейшая работа

Рассмотреть устойчивый собственный домен, независимое резервирование с пробным восстановлением и план безопасного перенаправления старых ссылок до отключения Render. Текущее состояние и команды обслуживания описаны в [DEPLOYMENT.md](../DEPLOYMENT.md).
