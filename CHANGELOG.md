# История изменений

## 0.3.0 — 2026-10-18

- Каталог и подготовленный кабинет опубликованы на rentalsign.onrender.com; 7 квартир и 79 фото проверены по HTTPS, прежние облачные договоры сохранены.

- Подготовленный кабинет: реальные квартиры вместо демоданных, поиск, отдельный архив, пакетное добавление каталога и быстрое создание договора.
- Приватный редактируемый шаблон по образцу, сохранённые реквизиты владельца, автозаполнение только новых договоров, необязательные удостоверения и адрес арендатора в HTML/PDF.
- Локальная команда подготовки с явным применением и безопасной очисткой только распознанных демоданных; seed не добавляет демо в уже заполненный кабинет.

- Публичный каталог 7 квартир с 79 фотографиями, поиском, сравнением цен, галереями и ссылками 2ГИС.
- Вход владельца с сохранением выбранной квартиры, повторяемое добавление в собственные объекты и предвыбор для договора.
- Разделение тарифа каталога и общей суммы договора; проверка ненулевого итога на сервере для квартир каталога.
- Добавочная связь `catalogSlug` для SQLite/PostgreSQL; существующие договоры и отправленные снимки сохраняются.

## 0.2.0 — 2026-10-13

- Бесплатное размещение Render + внешний Neon PostgreSQL с сохранением SQLite локально.
- Облачная сборка, отдельные миграции, безопасный повторный startup и readiness API.
- HTTPS-origin Render для персональных ссылок; Serializable транзакции с ограниченным retry.
- Работающий HTTPS-поддомен rentalsign.onrender.com; внешние ссылки, демодействие, PDF и PostgreSQL-конкурентность проверены на вымышленных данных.

## 0.1.0 — 2026-10-13

- Локальный RentalSign MVP: авторизация, объекты, договоры, защищённые ссылки, WhatsApp.
- Демонстрационное действие с серверным временем, журналом и блокировкой версии.
- Предварительные и итоговые PDF с кириллицей, A4 и номерами страниц.
- Вымышленный seed, CLI администратора, автоматические проверки и документация.
- Настоящая ЭЦП, юридическая проверка и production-развёртывание не включены.
